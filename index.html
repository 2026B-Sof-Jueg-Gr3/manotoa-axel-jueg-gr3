✨ El Alma del Juego Misión 1

Narrativa, propósito y resonancia ludonarrativa.

🎮

Logline

Una esfera cuántica debe destruir bloques de energía estancada para devolverle el color a una ciudad neón apagada. Cada ladrillo roto es un píxel de luz recuperado.

🔄

Resonancia Ludonarrativa

La mecánica —romper bloques— es la narrativa: el jugador restaura el color de la ciudad literalmente, ladrillo a ladrillo. El combo representa la inercia de la reconstrucción: a más bloques seguidos, más rápido se recupera el brillo.

📚

Valor Educativo

Diseñado para enseñar física arcade, colisiones, sistemas de partículas y arquitectura de escenas en Phaser 3. El código es legible y comentado para que cualquier estudiante pueda entenderlo y modificarlo.

⚖ Las Reglas del Mundo Real Misión 2

Marco legal y ético del juego.

Clasificación Creativa (PEGI / ESRB)

E

Clasificación E (Everyone): Apto para cualquier humano con pulso y un navegador. Contiene violencia mínima dirigida exclusivamente a bloques de energía inanimados que se desintegran en partículas de colores al ser impactados por una esfera cuántica. No hay sangre, no hay personajes, no hay diálogo ofensivo. Los bloques no sienten dolor (lo dice su licencia de software).

Muro de Honor

Créditos a los creadores del arte y sonido gratuito usado en este proyecto:

  • Texturas (ladrillos, bola, paleta, power-ups) CC0 · Generadas proceduralmente con Phaser Graphics
  • Fondo estrellado y halo radial CC0 · Canvas API + tileSprite
  • Efectos de sonido (rebote, combo, power-up) CC0 · Web Audio API (osciladores programáticos)
  • Motor de juego: Phaser 3.90 MIT · photonstorm.github.io
  • Fuente del sistema (Segoe UI / system-ui) Propietaria del SO · uso legítimo

Todo el código del proyecto está bajo licencia MIT y es de libre uso educativo. Si lo usas, menciona al autor.

🤖 Automatización Total (CI/CD) Misión Legendaria

GitHub Actions + Butler = cada push a main publica el juego en Itch.io automáticamente.

🔗

GitHub Actions

Workflow en .github/workflows/deploy-itchio.yml. Se activa en cada push a main, empaqueta el juego y lo sube con Butler.

🔒

Secrets

El API Key de Itch.io se guarda en Settings → Secrets and variables → Actions como ITCHIO_API_KEY. Nunca aparece en el código.

⚡

Butler CLI

La herramienta oficial de Itch.io para subir juegos desde la terminal. Se ejecuta dentro del workflow sin instalación local.
